# Сайт эксперта иностранных языков

Продающий лендинг эксперта по иностранным языкам: английский, немецкий, французский, корейский, китайский. Сайт с первого экрана формирует доверие, показывает ценность занятий и приводит посетителя к заявке на обучение.

## Что входит в сайт

- **Главный экран** — оффер «Заговорите на новом языке с первого месяца», подзаголовок, кнопка «Записаться», цифры доверия, премиальный фоновый рисунок.
- **Языки** — блок из пяти языков с описанием пользы изучения и тематической иллюстрацией.
- **Обо мне** — опыт и образование преподавателя, ключевые факты, результаты учеников.
- **Методика** — пошаговое описание методики и ответ, почему занятия дают результат.
- **Услуги и цены** — три тарифа («Разговорная практика», «Индивидуальная программа», «Интенсив к цели») и форма заявки (имя, контакт, язык, цель) с клиентской валидацией и подтверждением без серверной обработки.
- **Отзывы** — отзывы учеников с именем, изучаемым языком и достигнутым результатом.
- **Финальный призыв** — блок с призывом записаться и кнопкой к форме заявки.
- **Политика конфиденциальности** — отдельная страница `/privacy` с текстом обработки персональных данных, ссылка на неё — в подвале сайта.

## Стек

- Next.js (App Router) со статическим экспортом (`output: "export"`)
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- lucide-react (иконки)
- zod (валидация формы заявки)
- Sonner (уведомления)

## Команды

Установка зависимостей:

```bash
npm install
```

Запуск dev-сервера:

```bash
npm run dev
```

Проверки:

```bash
npm run typecheck   # проверка типов TypeScript
npm run lint        # ESLint
npm run format      # форматирование Prettier
npm run check       # lint + typecheck
```

Продакшен-сборка со статическим экспортом в `out/`:

```bash
npm run build
```

## Публикация на GitHub Pages

Сайт собирается как статический экспорт и публикуется в подпапке репозитория по адресу:

**https://bagryanoff.github.io/language-expert-site/**

Публикация происходит автоматически через GitHub Actions при пуше в ветку `main` (workflow `.github/workflows/deploy.yml`). Для этого в настройках репозитория нужно включить GitHub Pages:

1. Откройте репозиторий **language-expert-site** на GitHub.
2. Перейдите в **Settings** → **Pages** (раздел «Code and automation» в боковом меню).
3. В блоке **Build and deployment** в поле **Source** выберите вариант **GitHub Actions**.
4. Сохраните изменения (кнопка **Save**). Дальнейшие настройки не требуются — деплой будет выполнять workflow из `.github/workflows/deploy.yml`.
5. Убедитесь, что в репозитории есть ветка **main**: workflow запускается при пуше в неё.
6. После успешного запуска workflow на вкладке **Actions** сайт станет доступен по публичной ссылке **https://bagryanoff.github.io/language-expert-site/** (ссылка также появляется в разделе Settings → Pages после первой публикации).

> Примечание: так как сайт публикуется в подпапке, в `next.config.ts` заданы `basePath` и `assetPrefix` через переменную окружения `GITHUB_PAGES_BASE_PATH`. Она задаётся только при сборке для GitHub Pages в workflow `.github/workflows/deploy.yml` (значение `/language-expert-site`). По умолчанию (локально, предпросмотр) переменная не задана, и сайт собирается в корне без префикса путей.

## Структура проекта

```
app/
  layout.tsx          # корневой макет, шапка и подвал сайта
  page.tsx            # главная страница лендинга
  privacy/page.tsx    # страница политики конфиденциальности
  api/health/route.ts # статический артефакт здоровья платформы
  globals.css         # глобальные стили и визуальные утилиты
components/
  site-header.tsx     # липкая шапка с якорной навигацией
  hero-background.tsx # фон главного экрана
  languages-section.tsx, languages-illustration.tsx   # блок «Языки»
  about-section.tsx                                    # блок «Обо мне»
  methodology-section.tsx                              # блок «Методика»
  pricing-section.tsx, request-form.tsx,
  request-illustration.tsx                             # услуги, цены и форма заявки
  reviews-section.tsx                                  # блок «Отзывы»
  final-cta-section.tsx                                # финальный призыв
  ui/                # примитивы shadcn/ui
  bridge-provider.tsx, inspector-overlay.tsx           # preview-мост
lib/
  data.ts            # статические данные
  utils.ts           # вспомогательные утилиты
  bridge/            # хендшейк preview-моста
```
